# Project Roadmap

| Milestone | Scope | Status |
| --- | --- | --- |
| 1. Foundation | Repository setup, React client, Express API, TMDB proxy, local configuration | Complete |
| 2. Accounts | Registration, sign-in/out, profile and password changes, secure JWT cookie sessions, `user`/`admin` authorization, admin role management | Complete |
| 3. Movie & series discovery | TMDB discovery rails, movie/series switch, title panel, search overlay | Complete |
| 4. Personal library & curation | My List, Recently Explored, and admin-managed Only on Haruka catalog | Complete |
| 5. Streaming experience | Licensed player, viewing progress, Continue Watching, media delivery | Planned |
| 6. Release | Automated tests, deployment, monitoring, backup, security review, final documentation | Planned |
